## 第十批（✅ 已全部实现）

### I1. 整句/短语发音修复（双源链）✅
- 问题根因一：有道 dictvoice 是**词典音频**，只有单词/常用短语有录音（"Good morning" 有 18KB，"We're family" 返回 120 字节 JSON 错误）
- 问题根因二：百度 gettts 按 **Referer 反盗链**，页面带 Referer 时返回 HTML 错误页 → 播放失败
- 修复：index.html 加 `<meta name="referrer" content="no-referrer">`；speech.ts 重写为**双源链**：单词/短语 有道→百度→系统TTS；长句 百度 TTS 分块（≤100字符/块）→有道→TTS；会话打断管理（快速连点不串音）
- SW 缓存：有道 CacheFirst、百度改 **NetworkFirst**（避免偶发失败响应被缓存死），缓存名升版 v1/v2
- 实测：numerous（有道）✓、Good morning（有道词典音）✓、We're family（有道失败→百度接上 2.6s）✓、长句 4.8s ✓

### I2. 日常短语补库 ✅
- cn.json 新增 20+ 常用表达：早上好→Good morning、晚安→Good night、生日快乐→Happy birthday、不客气→You're welcome、我饿了→I'm hungry 等
- 短语候选标注「常用表达」，含空格的短语可直接出词典卡
